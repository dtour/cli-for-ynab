# CLI for YNAB v0.2.0

First public release of CLI for YNAB, a Python CLI for people and shell-based agents.

- All 44 operations in YNAB's official Python SDK are available through discoverable JSON schemas.
- Convenience commands cover categorization, allocation, category targets, multiple budgets, and spending reports.
- Routine categorization can run automatically. Other changes use reviewable proposals and explicit approval.
- General API writes include stale-state checks and local receipts to prevent repeated proposal application.
- Tokens use the OS keyring or an environment variable. Existing logins from the earlier local build remain readable.
- macOS installation and upgrades use Homebrew: `brew install dtour/tools/cli-for-ynab`.

The executable is `ynab`. Run `ynab --help` and `ynab guide` to get started.
This independent project is not affiliated with YNAB.
