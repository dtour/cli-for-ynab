# CLI for YNAB v0.2.1

- A rejected write now shows YNAB's own explanation in `error.details.reason` and the error message, for `api_apply_failed` and `apply_incomplete`. Tokens stay redacted.
- YNAB's built-in payees ("Starting Balance", "Manual Balance Adjustment", "Reconciliation Balance Adjustment") are refused as `payee_name` when a proposal is built (`reserved_payee`), instead of spending the single-use proposal on an HTTP 400.

Upgrade with `brew upgrade dtour/tools/cli-for-ynab`.
